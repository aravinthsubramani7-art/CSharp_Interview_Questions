Content Negotiation:
•	Content Negotiation is the process where the client and server decide the Web API response format (JSON/XML/etc.) using the Accept header.
•	By default, Web API send the response in JSON Format
•	Client requests response format → Server sends data in that format.
How Content Negotiation Works:
•	Client → Accept Header → Server → Response Format – This is the flow
•	Request  Accept: application/json
Response will be JSON
{
  "id": 1,
  "name": "Aravinth"
}
•	Request  Accept: application/xml
Response
<Employee>
   <Id>1</Id>
   <Name>Aravinth</Name>
</Employee>

What is content negotiation?
Mechanism used by Web API to return response in client requested format like JSON or XML.
Which header is used?
Accept
What happens if requested format is not supported?
406 Not Acceptable
when:
options.ReturnHttpNotAcceptable = true; is enabled
if it is not enabled it will return default json response for th rest of the requested format(like HTML, plain text, etc)
